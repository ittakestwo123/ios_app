# QingJian V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an offline-first SwiftUI iOS 17 study-focus application with SwiftData persistence, resilient timing, learning history, quotes, local notifications and the approved plum-and-bamboo paper visual system.

**Architecture:** A feature-first SwiftUI app uses a single SwiftData container and small `@MainActor` observable coordinators. Pure services (`StudyStatsService`, `FocusTimerEngine`, `DateKeyService`) have injected calendar/clock dependencies and XCTest coverage. Views consume query data and app settings without a networking layer.

**Tech Stack:** Swift 6-style SwiftUI, SwiftData, Swift Charts, UserNotifications, XCTest; iOS 17.0 minimum.

---

## Planned file structure

- `QingJian/App/`: app entry, root routing, SwiftData container.
- `QingJian/Core/DesignSystem/`: tokens, paper background, plum-bamboo decoration, shared cards and controls.
- `QingJian/Core/Models/`: SwiftData types and Codable active timer state.
- `QingJian/Core/Services/`: clock, timer engine, date aggregation, stats, quotes, notifications and CSV exporter.
- `QingJian/Features/`: Onboarding, Today, Focus, Journey, Quotes and Settings screens.
- `QingJian/Resources/`: `quotes.json` and offline image asset catalog.
- `QingJianTests/`: date/stat/timer service tests.
